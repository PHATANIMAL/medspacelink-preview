# MedSpaceLink preview (test build, LIVE mode against the development server)

This repository is a **test preview build** of the MedSpaceLink app, published so the app can be opened in a browser on a phone or computer.

It contains only the compiled static site (`dist/` from `PHATANIMAL/medspacelink-app` at commit `2a3c722`), built in **live mode against the MedSpaceHub development server** (a Replit development environment), not against medspacelink.com. It does not include source code, environment files, secrets, or the iOS project.

- Listings, accounts, rent requests and messages in this preview are **test data on the development database**. Nothing here touches the production website or its database.
- The development server can be asleep or restarting. If listings do not load, try again in a minute.
- Do not enter real patient information.

This is not the production website.
