# MedSpaceLink preview (test build)

This repository is a **test preview build** of the MedSpaceLink app, published so the app can be opened in a browser on a phone or computer.

It contains only the compiled static site (`dist/` from `PHATANIMAL/medspacelink-app` at commit `a81c1c1`), built in demo mode. It does not include source code, environment files, secrets, or the iOS project.

Listings in this preview are labeled demo listings so you can try the app. They are not real offices, and this build does not talk to the live medspacelink.com backend.

This is not the production website.
